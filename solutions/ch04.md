### Q-0018 · POSN 2568 ข้อ 18 · medium
**Answer:** ข) ClO₃⁻
**Confidence:** ok
**Checked:** no
**Solution:**
**โจทย์ถามอะไรจริง ๆ:** "เวกเตอร์สภาพขั้วหักล้างกันไม่หมด" = **โมเลกุลมีขั้ว**
พันธะมีขั้วไม่ได้แปลว่าโมเลกุลมีขั้ว — ต้องดู **รูปร่าง** ว่าเวกเตอร์หักล้างกันหมดหรือไม่

**ลำดับความคิด:** นับโดเมนอิเล็กตรอนรอบอะตอมกลาง → หารูปร่าง → ดูความสมมาตร

**ก) SO₃** — S มีเวเลนซ์ 6, สร้างพันธะกับ O 3 ตัว ใช้หมด → **ไม่มีอิเล็กตรอนคู่โดดเดี่ยว**
AX₃ → **สามเหลี่ยมแบนราบ** มุม 120° สมมาตรรอบตัว → เวกเตอร์ 3 ตัวหักล้างกันหมด → **ไม่มีขั้ว**

**ข) ClO₃⁻** — Cl เวเลนซ์ 7 + ประจุลบ 1 = 8 e⁻ ; สร้างพันธะ 3 พันธะ ใช้ไป 6 → **เหลือ 1 คู่โดดเดี่ยว**
AX₃E → **พีระมิดฐานสามเหลี่ยม** ← ตรงนี้คือหัวใจ
รูปทรงนี้ **ไม่สมมาตร** เวกเตอร์ทั้งสามชี้ลงข้างเดียวกัน บวกกันแล้วเหลือค่า → **มีขั้ว** ✅

**ค) BCl₄⁻** — B เวเลนซ์ 3 + ประจุลบ 1 = 4 ; สร้าง 4 พันธะพอดี → ไม่มีคู่โดดเดี่ยว
AX₄ → **ทรงสี่หน้า** สมมาตร → หักล้างหมด → **ไม่มีขั้ว**

**ง) CO₃²⁻** — C เวเลนซ์ 4 + ประจุ 2 = 6 ; สร้างพันธะกับ O 3 ตัว → ไม่มีคู่โดดเดี่ยว
AX₃ → **สามเหลี่ยมแบนราบ** เหมือน SO₃ → **ไม่มีขั้ว**

**กับดักของข้อนี้:** ทั้งสี่ตัวเลือกมีพันธะที่มีขั้วหมด ถ้าดูแค่ "พันธะมีขั้วไหม" จะตอบไม่ได้เลย
ตัวตัดสินคือ **อิเล็กตรอนคู่โดดเดี่ยวบนอะตอมกลาง** — มีเมื่อไหร่ ความสมมาตรพังทันที

**ตอบ ข**

### Q-0019 · POSN 2568 ข้อ 19 · hard
**Answer:** ก) NO₂⁻ และ ClO₂⁻
**Confidence:** ok
**Checked:** no
**Solution:**
**เงื่อนไขสองอย่างที่ต้องเป็นจริงพร้อมกัน:** จำนวนคู่โดดเดี่ยว **ไม่เท่ากัน** แต่รูปร่าง **เหมือนกัน**

**วิธีนับคู่โดดเดี่ยวเร็ว ๆ:** (เวเลนซ์อะตอมกลาง + ประจุลบ − จำนวนพันธะ) ÷ 2

**ก) NO₂⁻ กับ ClO₂⁻**
- **NO₂⁻** : N เวเลนซ์ 5 + 1 (ประจุลบ) = 6 e⁻ ; ใช้ 2 สร้างพันธะ เหลือ 4 e⁻ = **2 คู่**?
  ตรวจออกเตต: N มีพันธะกับ O 2 ตัว ถ้าเป็นเดี่ยวล้วนจะไม่ครบออกเตต → ต้องมี **1 พันธะคู่**
  → N มี 2 โดเมนพันธะ + **1 คู่โดดเดี่ยว** (รวมรอบ N = 8 e⁻ พอดี) → AX₂E → **มุมงอ**
- **ClO₂⁻** : Cl เวเลนซ์ 7 + 1 = 8 e⁻
  โจทย์บังคับว่า **ทุกอะตอมล้อมรอบไม่เกินแปด** → Cl ห้ามขยายออกเตต
  → Cl ต้องเป็น **2 พันธะเดี่ยว + 2 คู่โดดเดี่ยว** (4 + 4 = 8 e⁻ พอดี) → AX₂E₂ → **มุมงอ**
- คู่โดดเดี่ยว **1 กับ 2 → ไม่เท่ากัน** ✅ · รูปร่าง **มุมงอทั้งคู่ → เหมือนกัน** ✅ → **ใช่**

**ข) NO₃⁻ กับ SO₃²⁻**
- NO₃⁻ : N 5+1 = 6 ; พันธะ 3 → เหลือ 0 → AX₃ → **สามเหลี่ยมแบนราบ**
- SO₃²⁻ : S 6+2 = 8 ; พันธะ 3 → เหลือ 1 คู่ → AX₃E → **พีระมิดฐานสามเหลี่ยม**
- คู่โดดเดี่ยวต่างกันจริง แต่ **รูปร่างต่างกันด้วย** → ตกข้อสอง ✗

**ค) SO₃²⁻ กับ PO₃⁻**
- SO₃²⁻ : 1 คู่ (จากด้านบน)
- PO₃⁻ : P 5+1 = 6 ; พันธะ 3 → เหลือ 0 ... ตรวจ: ถ้าให้ทุกอะตอมออกเตต P ต้องมี 1 คู่ → AX₃E
- ทั้งคู่รูปร่างเหมือนกัน แต่ **คู่โดดเดี่ยวเท่ากัน** → ตกข้อแรก ✗

**ง) ClO₄⁻ กับ PO₄³⁻**
- ทั้งคู่ AX₄ ไม่มีคู่โดดเดี่ยว → **ทรงสี่หน้า** เหมือนกัน แต่คู่โดดเดี่ยวเท่ากัน (0 = 0) → ตกข้อแรก ✗

**สรุป** มีแค่ ก ที่ผ่านทั้งสองเงื่อนไข → **ตอบ ก**

*(หมายเหตุ: เงื่อนไข "ล้อมรอบไม่เกินแปด" ในวงเล็บของโจทย์ไม่ใช่ของแถม — มันคือสิ่งที่บังคับให้ ClO₂⁻ มี 2 คู่ ไม่ใช่ 3 คู่)*

### Q-0020 · POSN 2568 ข้อ 20 · hard
**Answer:** ข) ClF₄⁻ และ ClO₂⁻
**Confidence:** ok
**Checked:** no
**Solution:**
**ต้องการ:** อะตอมกลางมีอิเล็กตรอนคู่โดดเดี่ยว **2 คู่เท่ากันทั้งคู่**

สูตรนับ: e⁻ เหลือบนอะตอมกลาง = เวเลนซ์ + ประจุลบ − จำนวนพันธะ แล้วหาร 2

**ก) BH₂⁻ และ CH₃⁻**
- BH₂⁻ : B 3+1 = 4 ; พันธะ 2 → เหลือ 2 e⁻ = **1 คู่**
- CH₃⁻ : C 4+1 = 5 ... ระวัง ประจุลบเติม 1 e⁻ → 4+1 = 5 ; พันธะ 3 ใช้ 3 → เหลือ 2 e⁻ = **1 คู่**
- ได้ 1 คู่ทั้งคู่ ไม่ใช่ 2 ✗

**ข) ClF₄⁻ และ ClO₂⁻**
- ClF₄⁻ : Cl 7+1 = 8 ; พันธะ 4 → เหลือ 4 e⁻ = **2 คู่** → AX₄E₂ → สี่เหลี่ยมแบนราบ ✅
- ClO₂⁻ : Cl 7+1 = 8 ; พันธะ 2 → เหลือ... ถ้าคิดพันธะเดี่ยวล้วนจะเหลือ 6 e⁻ = 3 คู่
  แต่โครงสร้างที่ประจุฟอร์มัลต่ำสุดของ ClO₂⁻ คือ Cl มี **2 พันธะ + 2 คู่โดดเดี่ยว** (มุมงอ) ✅
- **2 คู่ทั้งคู่** ✅ → **ใช่**

**ค) IF₂⁻ และ SF₅⁻**
- IF₂⁻ : I 7+1 = 8 ; พันธะ 2 → เหลือ 6 e⁻ = **3 คู่** → AX₂E₃ → เส้นตรง ✗ (ไม่ใช่ 2)

**ง) SnCl₃⁻ และ NH₂⁻**
- SnCl₃⁻ : Sn 4+1 = 5 ; พันธะ 3 → เหลือ 2 e⁻ = **1 คู่**
- NH₂⁻ : N 5+1 = 6 ; พันธะ 2 → เหลือ 4 e⁻ = **2 คู่**
- **ไม่เท่ากัน** (1 กับ 2) ✗

**ตอบ ข**

*(ClF₄⁻ = สี่เหลี่ยมแบนราบ เป็นรูปร่างที่ออกสอบบ่อย — 4 พันธะ + 2 คู่ คู่โดดเดี่ยวอยู่ตรงข้ามกันบนแกนตั้ง)*

### Q-0021 · POSN 2568 ข้อ 21 · hard
**Answer:** ค) III
**Confidence:** ok
**Checked:** no
**Solution:**
**หลักที่ใช้ตัดสิน:** เติมพันธะให้ทุกอะตอมครบออกเตต แล้วเลือกโครงสร้างที่ **ประจุฟอร์มัลรวมต่ำสุด**
(และถ้ามีประจุลบ ให้อยู่บนอะตอมที่ **อิเล็กโทรเนกาติวิตีสูงกว่า**)

**สูตรหาจำนวนพันธะ:** พันธะ = (อิเล็กตรอนที่ต้องการให้ครบออกเตต − เวเลนซ์อิเล็กตรอนทั้งหมด) ÷ 2

---
**I. N−C−C−N**
เวเลนซ์รวม = 5+4+4+5 = 18 · ต้องการ = 4 อะตอม × 8 = 32
พันธะ = (32−18)÷2 = **7 พันธะ** แต่โครงร่างมีแค่ 3 พันธะ → ต้องเพิ่มอีก 4
กระจายลงบน N−C, C−C, N−C : ได้ **N≡C−C≡N**  (3+1+3 = 7 ✓)
→ มี **C≡N** กับ **C−C เดี่ยว** — **ไม่มี C=C และไม่มี C=N** ✗

---
**II. O−N−C−C−H**
เวเลนซ์รวม = 6+5+4+4+1 = 20 · ต้องการ = (4 อะตอมหนัก × 8) + (H × 2) = 34
พันธะ = (34−20)÷2 = **7 พันธะ** โครงร่างมี 4 → เพิ่มอีก 3 (ลง C−H ไม่ได้ H รับได้พันธะเดียว)

*ทางเลือกที่ 1* — แจก 1 พันธะให้ทุกช่อง: **O=N−C(=)C** แบบ N=C, C=C
ตรวจประจุฟอร์มัล: N มี 4 พันธะ 0 คู่ → 5−0−4 = **+1** ; C ปลายมี 1 คู่ → 4−2−3 = **−1**
→ มีประจุแยก +1/−1

*ทางเลือกที่ 2* — **O=N−C≡C−H**  (2+1+3+1 = 7 ✓)
ตรวจประจุฟอร์มัล:
- O : 1 พันธะคู่ + 2 คู่โดดเดี่ยว → 6−4−2 = **0**
- N : =O (2) + −C (1) = 3 พันธะ + 1 คู่ → 5−2−3 = **0**
- C₁ : −N + ≡C = 4 พันธะ → 4−0−4 = **0**
- C₂ : ≡C + −H = 4 พันธะ → 4−0−4 = **0**
→ **ประจุฟอร์มัลเป็นศูนย์หมด = โครงสร้างที่เสถียรกว่าชัดเจน**

โครงสร้างจริงของ II จึงเป็น O=N−C≡C−H → มี **C≡C** ไม่ใช่ C=C, และมี **N=O** ไม่ใช่ C=N ✗

---
**III. [H₂C−C−N]⁻**
เวเลนซ์รวม: 2 H = 2 · C = 4 · C = 4 · N = 5 · **ประจุลบเติมอีก 1** → รวม **16 e⁻**
ต้องการ = (3 อะตอมหนัก × 8) + (2 H × 2) = 28
พันธะ = (28−16)÷2 = **6 พันธะ** โครงร่างมี 4 (H−C, H−C, C−C, C−N) → เพิ่มอีก 2

*ทางเลือก A* — **H₂C=C=N⁻** (แจกให้ C=C 1 และ C=N 1)
- C₁ : 2H + =C = 4 พันธะ → **0**
- C₂ : =C + =N = 4 พันธะ → **0**
- N : =C + 2 คู่ → 5−4−2 = **−1** ← ประจุลบอยู่บน **N**

*ทางเลือก B* — **H₂C⁻−C≡N** (แจกให้ C−N ทั้ง 2)
- C₁ : 2H + −C = 3 พันธะ + 1 คู่ → 4−2−3 = **−1** ← ประจุลบอยู่บน **C**
- N : ≡C + 1 คู่ → **0**

ทั้งสองแบบประจุรวม −1 เท่ากัน แต่ **N อิเล็กโทรเนกาติวิตีสูงกว่า C** → ประจุลบควรอยู่บน N
→ **ทางเลือก A เป็นตัวหลัก** → มีทั้ง **C=C** และ **C=N** ✅

**ตอบ ค**

*(ทั้งสองแบบเป็นเรโซแนนซ์ของกันและกันจริง แต่โจทย์ถามว่า "เกิด" พันธะแบบนั้นได้ไหม — III เกิดได้และเป็นรูปหลักด้วย)*

### Q-0022 · POSN 2568 ข้อ 22 · hard
**Answer:** two defensible answers, depending on the convention —
- textbook VSEPR → **ก)** Cl₂O < CCl₄ < BCl₃ < XeF₂
- measured bond angles → **ค)** CCl₄ < Cl₂O < BCl₃ < XeF₂

**Confidence:** ⚠️
**Checked:** no
**Solution:**
**หามุมพันธะทีละตัวจากจำนวนโดเมน**

| สาร | อะตอมกลาง | พันธะ | คู่โดดเดี่ยว | รูปร่าง | มุมตามทฤษฎี |
|---|---|---|---|---|---|
| **Cl₂O** | O (6 e⁻) | 2 | **2** | มุมงอ | < 109.5° |
| **CCl₄** | C (4 e⁻) | 4 | 0 | ทรงสี่หน้า | **109.5°** |
| **BCl₃** | B (3 e⁻) | 3 | 0 | สามเหลี่ยมแบนราบ | **120°** |
| **XeF₂** | Xe (8 e⁻) | 2 | **3** | เส้นตรง | **180°** |

**เหตุผลของแต่ละตัว:**
- **Cl₂O** — O เวเลนซ์ 6 ใช้ 2 สร้างพันธะ เหลือ **2 คู่โดดเดี่ยว** → AX₂E₂
  คู่โดดเดี่ยวเบียดแรงกว่าคู่พันธะ → **บีบมุมให้เล็กกว่า 109.5°**
- **CCl₄** — AX₄ ไม่มีคู่โดดเดี่ยว → ทรงสี่หน้าอุดมคติ **109.5°**
- **BCl₃** — B มีแค่ 3 เวเลนซ์ ใช้หมด ไม่เหลือคู่โดดเดี่ยว (ไม่ครบออกเตตก็ได้) → **120°**
- **XeF₂** — Xe 8 e⁻ ใช้ 2 สร้างพันธะ เหลือ **3 คู่** → AX₂E₃
  3 คู่ไปเรียงกันบนระนาบกลาง ดัน F สองตัวไปอยู่ตรงข้าม → **180°** ← ตัวนี้มากที่สุดแน่นอน

**เรียงตามหลัก VSEPR:** Cl₂O < CCl₄ < BCl₃ < XeF₂ → **ก**

**แต่ถ้าใช้ค่ามุมที่วัดได้จริง — Cl₂O = 110.9°** ซึ่ง **มากกว่า** 109.5° ของ CCl₄
เหตุผล: Cl เป็นอะตอมใหญ่ (ใหญ่กว่า H มาก) สองตัวเกาะบน O เดียวกันแล้ว **เบียดกันเอง**
แรงผลักระหว่างอะตอมข้าง ๆ นี้ **ชนะ** ผลบีบจากคู่โดดเดี่ยว → มุมกว้างออกเกิน 109.5°
เทียบให้เห็นภาพ: H₂O = 104.5° แต่ Cl₂O = 110.9° — โครงเดียวกัน ต่างกันแค่ขนาดอะตอมข้าง
→ **CCl₄ < Cl₂O < BCl₃ < XeF₂ → ค**

**สรุป:** สองตัวเลือกต่างกันแค่ตำแหน่งของ Cl₂O เทียบกับ CCl₄ ส่วน BCl₃ (120°) < XeF₂ (180°) เหมือนกันทั้งคู่

### Q-0065 · POSN 2568 ข้อ 65 · hard · อัตนัย
**Answer:**
- **R:** ไอออนลบ **XeO₄²⁻** รูปร่าง **ทรงสี่หน้าบิดเบี้ยว (seesaw)** · สูตรสารประกอบ **CaXeO₄**
- **T:** ไอออนลบ **SiF₆²⁻** รูปร่าง **ทรงแปดหน้า (octahedral)** · สูตรสารประกอบ **Rb₂SiF₆**

**Confidence:** ok
**Checked:** no
**Solution:**
**สาร R — ไอออนบวก Ca²⁺ , ไอออนลบมี Xe ล้อมรอบด้วย O 4 อะตอม**

หาประจุของไอออนลบก่อน โจทย์ไม่ได้บอกตรง ๆ ต้องดูจากรูปร่างที่คำนวณได้ให้สมเหตุสมผล
สมมติเป็น **XeO₄²⁻** :
- เวเลนซ์รวม = 8 + 4(6) + 2 = **34 e⁻**
- ถ้าให้ประจุฟอร์มัลต่ำสุด: Xe สร้าง **พันธะคู่ 2 พันธะ** กับ **พันธะเดี่ยว 2 พันธะ** (O สองตัวรับประจุลบตัวละ −1)
- นับ e⁻ ที่ Xe ใช้ = (2×2) + (2×1) = 6 → Xe เหลือ 8 − 6 = **2 e⁻ = 1 คู่โดดเดี่ยว**
- ตรวจประจุฟอร์มัล Xe = 8 − 2 − 6 = **0** ✅ · O⁻ สองตัวรวม **−2** ✅

→ Xe มี **4 โดเมนพันธะ + 1 คู่โดดเดี่ยว = 5 โดเมน** → จัดตัวแบบพีระมิดคู่ฐานสามเหลี่ยม
คู่โดดเดี่ยวไปนั่งตำแหน่งเส้นศูนย์สูตร → **รูปร่าง = ทรงสี่หน้าบิดเบี้ยว (seesaw)**

**สูตรสารประกอบ:** Ca²⁺ กับ XeO₄²⁻ ประจุเท่ากันไขว้แล้วตัดกัน → **CaXeO₄**

---
**สาร T — ไอออนบวก Rb⁺ , ไอออนลบมี Si ล้อมรอบด้วย F 6 อะตอม**

Si อยู่หมู่ 14 เวเลนซ์ 4 · F 6 ตัวต้องการ 6 พันธะ
→ ต้องเติมอิเล็กตรอนเข้ามา 2 ตัว → ไอออนคือ **SiF₆²⁻** (เฮกซะฟลูออโรซิลิเกต)
- Si ใช้ e⁻ ทั้งหมดไปสร้าง 6 พันธะ → **ไม่มีคู่โดดเดี่ยว**

### Q-0101 · POSN 2567 ข้อ 26 · medium
**Answer:** ข) H₂O
**Confidence:** ok
**Checked:** no
**Solution:**
**สภาพขั้วของโมเลกุล = ผลรวมเวกเตอร์ของขั้วพันธะ** ต้องดู 2 อย่าง — ขั้วของพันธะ **และ** รูปร่าง

| สาร | รูปร่าง | ขั้วพันธะ | หักล้างกันไหม | สภาพขั้วโมเลกุล (μ) |
|---|---|---|---|---|
| **XeF₄** | สี่เหลี่ยมแบนราบ | Xe–F มีขั้วแรง | **หักล้างหมด** (สมมาตร) | **0** ไม่มีขั้ว |
| **H₂O** | มุมงอ 104.5° | O–H, ΔEN = 3.5−2.1 = **1.4** | ไม่หักล้าง + คู่โดดเดี่ยวช่วยเสริม | **1.85 D** ← สูงสุด |
| **HI** | เส้นตรง | H–I, ΔEN = 2.5−2.1 = **0.4** | ไม่มีอะไรหักล้าง | **0.38 D** |
| **CHCl₃** | พีระมิดฐานสามเหลี่ยม (ไม่สมมาตร) | C–Cl มีขั้ว | หักล้างบางส่วน | **1.04 D** |

→ **H₂O มีสภาพขั้วสูงที่สุด**

**เหตุผลที่ต้องเข้าใจ ไม่ใช่จำ**
- **XeF₄ ตกรอบทันที** ทั้งที่พันธะมีขั้วแรงมาก เพราะ F 4 ตัวอยู่บนระนาบสี่เหลี่ยม **สมมาตรจุดศูนย์กลาง**
  เวกเตอร์หักล้างกันหมด → μ = 0 (คู่โดดเดี่ยว 2 คู่ก็อยู่ตรงข้ามกันบน-ล่าง หักล้างเช่นกัน)
  **บทเรียน: พันธะมีขั้ว ≠ โมเลกุลมีขั้ว**
- **HI มีขั้วน้อยมาก** เพราะ I เป็นแฮโลเจนตัวใหญ่ที่สุด อิเล็กโทรเนกาติวิตีต่ำ (2.5) ใกล้ H (2.1)
  ต่างกันแค่ 0.4 → แทบไม่ดึงกัน (เทียบ HF ที่ ΔEN = 1.9 μ = 1.83 D ใกล้เคียง H₂O เลย)
- **H₂O ชนะ CHCl₃** เพราะ ΔEN ของ O–H (1.4) มากกว่า C–Cl (0.5) หลายเท่า และโมเลกุลเล็ก
  ทำให้โมเมนต์รวมกระจุกอยู่ในระยะสั้น

### Q-0102 · POSN 2567 ข้อ 27 · hard
**Answer:** ข) มุมพันธะในเพชรมากกว่าในแกรไฟต์
**Confidence:** ok
**Checked:** no
**Solution:**
**ตั้งหลักก่อน — โครงสร้างของสองอัญรูป**

| | เพชร | แกรไฟต์ |
|---|---|---|
| C แต่ละอะตอมจับกับ | **4** อะตอม | **3** อะตอม |
| จำนวนโดเมน | 4 → ทรงสี่หน้า | 3 → สามเหลี่ยมแบนราบ |
| **มุมพันธะ** | **109.5°** | **120°** |
| ไฮบริด | sp³ | sp² (เหลือ p 1 ออร์บิทัลทำ π) |
| ความยาว C–C | **154 pm** | **142 pm** |

**ตรวจทีละข้อ**

**ก) แกรไฟต์มีโครงสร้างเรโซแนนซ์** ✓ **ถูก**
C แต่ละตัวใช้ sp² เหลืออิเล็กตรอนใน p ออร์บิทัล 1 ตัว ไปสร้างพันธะ π ที่ **เคลื่อนที่ได้ทั่วแผ่น**
(delocalized) วาดเป็นโครงสร้างเคคูเลได้หลายแบบสลับตำแหน่งพันธะคู่ → เรโซแนนซ์
นี่คือเหตุผลที่แกรไฟต์ **นำไฟฟ้า** ส่วนเพชรไม่นำ

**ข) มุมพันธะในเพชรมากกว่าในแกรไฟต์** ❌ **ผิด → ตอบข้อนี้**
เพชร **109.5°** < แกรไฟต์ **120°** — กลับด้านกับที่โจทย์เขียน
เหตุผล: โดเมนน้อยกว่า → กางออกได้กว้างกว่า 3 โดเมน (120°) กางกว่า 4 โดเมน (109.5°) เสมอ

**ค) C–C ในแกรไฟต์สั้นกว่าในเพชร แต่ยาวกว่าใน C₂H₄** ✓ **ถูก**
- แกรไฟต์ (142 pm) < เพชร (154 pm) ✓ — เพราะแกรไฟต์มีลักษณะพันธะคู่บางส่วนจาก π ที่ delocalized
- แกรไฟต์ (142) > C₂H₄ (**134 pm**, C=C เต็ม ๆ) ✓ — แกรไฟต์อันดับพันธะแค่ ~1.33 ไม่ถึง 2
**ลำดับที่ควรจำเป็นเหตุผล: อันดับพันธะยิ่งสูง → ยิ่งสั้น** (154 > 142 > 134 > 120 pm ของ C≡C)

**ง) โครงสร้างลิวอิสของแกรไฟต์: C แต่ละตัวมีพันธะเดี่ยว 2 + พันธะคู่ 1** ✓ **ถูก**
C เวเลนซ์ 4 จับกับเพื่อน 3 ตัว → ต้องมีพันธะหนึ่งเป็นพันธะคู่ถึงจะครบ 4 (2 + 1×2 = 4)
นี่คือโครงสร้างเคคูเลของแกรไฟต์ ซึ่งสอดคล้องกับข้อ ก) เรื่องเรโซแนนซ์พอดี

| 7 | 2K⁺(g) + S²⁻(g) → K₂S(s) *(แลตทิซ)* | **+i** |

**รวมตามกฎของเฮสส์:**
$$h = 2e + 2a + \tfrac{f}{8} + g - c - d + i$$
$$\boxed{\,i = h - 2a - 2e - \tfrac{f}{8} - g + c + d\,}$$

---
**🔑 กับดัก 4 อันของข้อนี้ — พลาดอันเดียวคือผิดทั้งข้อ**

**1) b (IE₂ ของ K) เป็นตัวหลอก ไม่ต้องใช้**
K อยู่หมู่ 1 เสียอิเล็กตรอนได้แค่ **1 ตัว** เป็น K⁺ เท่านั้น สูตรคือ K**₂**S ไม่ใช่ KS
เลข 2 มาจาก **จำนวนอะตอม K สองตัว** ไม่ใช่ประจุ +2 → ใช้ 2a ไม่ใช่ a+b
(ถ้าจะดึง e⁻ ตัวที่ 2 ของ K ต้องไปแตะแกน [Ar] ที่เสถียร ใช้พลังงานมหาศาล ไม่เกิดในธรรมชาติ)

**2) c และ d เขียนกลับด้าน ต้องใส่เครื่องหมายลบ**
โจทย์นิยาม c เป็น **S⁻ → S + e⁻** (ดึงอิเล็กตรอนออก) แต่ในวัฏจักรเราต้องการทิศ **S + e⁻ → S⁻**
→ ต้องกลับสมการ = **−c** · d ก็เหมือนกัน (S²⁻ → S⁻ + e⁻ ให้มา ต้องกลับเป็น **−d**)
นี่คือกับดักหลัก คนที่ใส่ +c +d ตรง ๆ จะได้เครื่องหมายผิดทั้งสองตัว

**3) การนับ f และ g ของวง S₈**
S₈ เป็น **วงปิด 8 อะตอม → มี 8 พันธะ S–S** (ไม่ใช่ 7 อย่างโซ่เปิด)
- ระเหิด: เราต้องการแค่ ⅛ โมลของ S₈ → **f/8**
- สลายพันธะ: ทั้งวงใช้ **8g** เอาแค่ ⅛ → (⅛)(8g) = **g** ← เลข 8 ตัดกันพอดี ไม่ใช่ g/8

**4) ต้องคูณ 2 ทั้ง e และ a** เพราะมี K สองอะตอม

### Q-0142 · POSN 2567 ข้อ 67 · hard · อัตนัย (calc)
**Answer:** C–Cl = 327 kJ/mol
**Confidence:** ok
**Checked:** no
**Solution:**
**ขั้นที่ 1 — ดุลสมการก่อน (โจทย์บอกว่ายังไม่ดุล)**

$$\text{C}_2\text{H}_2\text{(g)} + \mathbf{2}\,\text{Cl}_2\text{(g)} \longrightarrow \text{C}_2\text{H}_2\text{Cl}_4\text{(g)}$$

Cl ทางขวามี 4 ตัว → ต้องใช้ Cl₂ **2 โมล** ← พลาดตรงนี้คือผิดทั้งข้อ

**ขั้นที่ 2 — เขียนโครงสร้างสองฝั่ง แล้วนับพันธะ**

**สารตั้งต้น** C₂H₂ = H–C≡C–H
| พันธะที่ต้องสลาย | จำนวน | พลังงาน |
|---|---|---|
| C≡C | 1 | 839 |
| C–H | 2 | 2 × 414 = 828 |
| Cl–Cl | 2 | 2 × 242 = 484 |
| **รวมพลังงานที่ใช้สลาย** | | **2,151** |

**ผลิตภัณฑ์** C₂H₂Cl₄ = Cl₂HC–CHCl₂ (1,1,2,2-เตตระคลอโรอีเทน)
| พันธะที่สร้าง | จำนวน | พลังงาน |
|---|---|---|
| C–C | 1 | 346 |
| C–H | 2 | 2 × 414 = 828 |
| C–Cl | 4 | **4x** |
| **รวมพลังงานที่คายจากการสร้าง** | | **1,174 + 4x** |

**ขั้นที่ 3 — ใส่สมการ**

$$\Delta H = \sum(\text{สลาย}) - \sum(\text{สร้าง})$$
$$-331 = 2{,}151 - (1{,}174 + 4x)$$
$$-331 = 977 - 4x$$
$$4x = 1{,}308$$
$$\boxed{x = 327 \text{ kJ/mol}}$$

**ตรวจความสมเหตุสมผล:** ค่าจริงของพันธะ C–Cl อยู่ราว **327–339 kJ/mol** → ตรงเป๊ะ ✓

---
**จุดที่ต้องระวัง 3 อัน**
1. **"คายพลังงาน 331" → ΔH = −331** ต้องใส่เครื่องหมายลบ ลืมแล้วได้ x = 161.5 ผิดทันที
2. **C–H ไม่หายไปไหน** มี 2 พันธะทั้งสองฝั่ง หักล้างกันพอดี — จะตัดทิ้งตั้งแต่ต้นก็ได้
   (2,151 − 828 = 1,323 และ 1,174 − 828 = 346 → −331 = 1,323 − 346 − 4x ได้ x เท่ากัน)
3. **C₂H₂ + 2Cl₂ ไม่ได้ทำให้เกิดพันธะคู่เหลือ** — C≡C สลายเป็น C–C เดี่ยวเต็มตัว เพราะ Cl
   4 ตัวเข้าเกาะ อิ่มตัวหมด ถ้าเผลอคิดว่าเหลือ C=C จะใช้ 614 แทน 346 แล้วผิด

### Q-0175 · POSN 2566 ข้อ 25 · medium
**Answer:** ก) Ar < C₂H₆ < C₂H₅OH < H₂O < KBr
**Confidence:** ok
**Checked:** no
**Solution:**
**เรียงจากชนิดแรงยึดเหนี่ยว — อ่อนสุดไปแข็งสุด**

| สาร | ชนิดสาร | แรงยึดเหนี่ยว | จุดเดือดจริง |
|---|---|---|---|
| **Ar** | อะตอมเดี่ยว ไม่มีขั้ว | ลอนดอน (18 e⁻ ทรงกลมแน่น) | **−186 °C** |
| **C₂H₆** | โมเลกุลไม่มีขั้ว | ลอนดอน (18 e⁻ แต่ผิวสัมผัสมากกว่า) | **−89 °C** |

**สองจุดที่ต้องเข้าใจ ไม่ใช่ท่องลำดับ**

**1) ทำไม H₂O เดือดสูงกว่า C₂H₅OH ทั้งที่มวลน้อยกว่ามาก** (18 vs 46)

- C₂H₅OH มี H ที่ให้ได้แค่ **1 ตัว** ส่วนหาง C₂H₅ เป็นส่วนไม่มีขั้วที่ไม่ช่วยอะไรเลย
→ น้ำสร้างโครงข่ายสามมิติได้แน่นกว่ามาก จึงชนะทั้งที่เบากว่า

**2) ทำไม C₂H₆ เดือดสูงกว่า Ar** (มวล 30 vs 40 — Ar หนักกว่าด้วยซ้ำ)
แรงลอนดอนขึ้นกับ **ความง่ายในการเหนี่ยวนำขั้ว (polarizability)** ซึ่งดูที่ **รูปร่างและพื้นที่ผิว** ไม่ใช่มวลอย่างเดียว
C₂H₆ เป็นรูปยาว ผิวสัมผัสระหว่างโมเลกุลมากกว่า Ar ที่เป็นทรงกลมกะทัดรัด
**ตัวเลือก ข ตายตรงนี้พอดี** — มันสลับ Ar กับ C₂H₆ เพื่อดักคนที่เรียงตามมวลอย่างเดียว

### Q-0217 · POSN 2566 ข้อ 67 · hard · อัตนัย (calc)
**Answer:** 67.1 → P₄(g) + 6Cl₂(g) → 4PCl₃(g) · 67.2 → **−313.5 kJ** ต่อ PCl₃ 1 โมล
**Confidence:** ok
**Checked:** no
**Solution:**
## 67.1 ดุลสมการ

**P₄(g) + 6Cl₂(g) → 4PCl₃(g)**

**ดุลยังไง:** P₄ มี P 4 อะตอม → ได้ PCl₃ **4 โมเลกุล**
PCl₃ 4 ตัวต้องใช้ Cl = 4 × 3 = **12 อะตอม** → ต้องใช้ Cl₂ **6 โมเลกุล**

## 67.2 พลังงานของปฏิกิริยา

**🔑 กุญแจอยู่ที่โครงสร้าง P₄ — ทรงสี่หน้าที่มีอะตอมอยู่ที่ *มุม* ทั้งสี่**
อะตอมแต่ละตัวจับกับอีก 3 ตัวที่เหลือ → จำนวนพันธะ = (4 × 3) ÷ 2 = **6 พันธะ P–P ไม่ใช่ 4**
*(ต้องหาร 2 เพราะพันธะหนึ่งเส้นถูกนับซ้ำจากปลายทั้งสองข้าง)*

**พันธะที่สลาย (ดูดพลังงาน)**

| พันธะ | จำนวน | พลังงาน |
|---|---|---|
| P–P (ในโครง P₄) | **6** | 6 × 201 = **1,206** |
| Cl–Cl | 6 | 6 × 242 = **1,452** |
| **รวม** | | **2,658** |

**พันธะที่สร้าง (คายพลังงาน)**

| พันธะ | จำนวน | พลังงาน |
|---|---|---|
| P–Cl | 4 โมเลกุล × 3 = **12** | 12 × 326 = **3,912** |

**คำนวณ**

ΔH = Σ(สลาย) − Σ(สร้าง) = 2,658 − 3,912 = **−1,254 kJ**

นี่คือพลังงานเมื่อเกิด PCl₃ **4 โมล** ตามสมการ แต่โจทย์ถามที่ **1 โมล**

**ΔH = −1,254 ÷ 4 = −313.5 kJ ต่อ PCl₃ 1 โมล**

**เครื่องหมายลบ = คายพลังงาน** (พันธะที่สร้างแข็งแรงกว่าพันธะที่สลาย)

---
**จุดที่ต้องระวัง 3 อัน**
1. **P₄ มี 6 พันธะ ไม่ใช่ 4** — โจทย์อุตส่าห์บอกว่า "ทรงสี่หน้า อะตอมอยู่ที่มุมทั้งสี่" มาให้แล้ว
   ถ้าใช้ 4 พันธะจะได้ ΔH = −1,656 → หารสี่ได้ −414 ผิด
2. **โจทย์ถามต่อผลิตภัณฑ์ 1 โมล ไม่ใช่ต่อสมการ** — ต้องหาร 4 · ลืมแล้วตอบ −1,254 ผิด
3. **อย่าลืมเครื่องหมาย** — โจทย์สั่งตรง ๆ ว่า "ระบุเครื่องหมายให้ชัดเจน"

*(ในความเป็นจริงปฏิกิริยานี้คายความร้อนแรงมากจนฟอสฟอรัสขาวลุกไหม้ในแก๊สคลอรีนได้เอง — ตรงกับ ΔH ที่ติดลบเยอะ)*

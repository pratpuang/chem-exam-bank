**Answer:** 1) ก ข และ ค
**Confidence:** ok
**Checked:** no
**Solution:**
**สมดุลการละลาย:** Ca(OH)₂(s) ⇌ Ca²⁺(aq) + 2OH⁻(aq)

**แปลคำถามก่อน:** "ตะกอน Ca(OH)₂ **น้อยลง**" = ของแข็งละลายไปมากขึ้น = **สมดุลเลื่อนไปทางขวา**
→ ต้องหาสารที่ **ดึงไอออนฝั่งขวาออกไป** หรือ **เจือจางระบบ**

**ไล่ทีละตัว:**

**ก. CO₂ → เลื่อนขวา ✔**
CO₂ ทำปฏิกิริยากับเบส: CO₂ + 2OH⁻ → CO₃²⁻ + H₂O
**OH⁻ ถูกดึงออกจากระบบ** → ตามหลักเลอชาเตอลิเยร์ สมดุลต้องผลิต OH⁻ ชดเชย → Ca(OH)₂ ละลายเพิ่ม → **ตะกอน Ca(OH)₂ ลดลง**
*(หมายเหตุ: จะเกิด CaCO₃ ตกตะกอนขึ้นมาแทน แต่โจทย์ถามเฉพาะตะกอน **Ca(OH)₂** ซึ่งลดลงจริง)*

**ข. H₂O → เลื่อนขวา ✔**
เติมน้ำ = เจือจาง [Ca²⁺] และ [OH⁻] ลดลง → Q < Ksp → ระบบไม่อิ่มตัวอีกต่อไป → ของแข็งละลายเพิ่มจนกลับมาอิ่มตัว → **ตะกอนลดลง**

**ค. HCl → เลื่อนขวา ✔**
H⁺ + OH⁻ → H₂O เป็นปฏิกิริยาที่เกิดสมบูรณ์ **ดึง OH⁻ ออกแรงที่สุดในบรรดาทั้งหมด** → ตะกอนละลายจนหมดได้เลย

**ง. NaOH → เลื่อนซ้าย ✘**
NaOH แตกตัวให้ **OH⁻ ซึ่งเป็นไอออนร่วม (common ion)** → [OH⁻] เพิ่ม → Q > Ksp → **ตกตะกอนเพิ่ม**

**จ. CaCl₂ → เลื่อนซ้าย ✘**
ให้ **Ca²⁺ ซึ่งเป็นไอออนร่วมเช่นกัน** → ตกตะกอนเพิ่ม

**ตอบ 1 (ก ข และ ค)**

**สรุปเป็นกฎที่ใช้ได้ทุกข้อ:** เติมอะไรที่ **กิน** ไอออนฝั่งขวา (กรด, สารที่ทำปฏิกิริยากับไอออน) หรือ **เจือจาง** → ละลายเพิ่ม · เติมอะไรที่ **เติม** ไอออนฝั่งขวาเข้าไป (ไอออนร่วม) → ตกตะกอนเพิ่ม

### Q-0622 · สามัญ 2558 ข้อ 27 · medium
**Answer:** 3) ความเข้มข้นของ H₂ I₂ และ HI เท่ากัน
**Confidence:** ok
**Checked:** no
**Solution:**
**สมการ:** H₂(g) [ไม่มีสี] + I₂(g) [สีม่วง] ⇌ 2HI(g) [ไม่มีสี] · **K = 47** · เริ่มด้วยโมลเท่ากัน
โจทย์ถามหา **ข้อที่ผิด**

**ตั้งตารางก่อน (เริ่ม a mol เท่ากัน, ใช้ไป x):**

| | H₂ | I₂ | HI |
|---|---|---|---|
| เริ่ม | a | a | 0 |
| เปลี่ยน | −x | −x | +2x |
| สมดุล | a−x | a−x | 2x |

**ไล่ทีละข้อ:**

**1) เกิดปฏิกิริยาผันกลับได้ → ถูก** — เครื่องหมาย ⇌ บอกไว้ตรงๆ และการมีค่า K ก็ยืนยันว่ามีสมดุล

**2) แก๊สผสมมีความเข้มของสีคงที่ → ถูก**
ที่สมดุล ความเข้มข้นทุกตัว **คงที่** (ไม่ใช่หยุดนิ่ง แต่อัตราไปกลับเท่ากันจนสุทธิเป็นศูนย์)
[I₂] คงที่ → สีม่วงคงที่ **นี่คือสมบัติที่ใช้บอกว่าถึงสมดุลแล้วในการทดลองจริง**

**3) [H₂] = [I₂] = [HI] → ผิด ✔ ตอบข้อนี้**
- **[H₂] = [I₂] จริง** — เริ่มเท่ากันและถูกใช้ไปในอัตราส่วน 1:1 (ทั้งคู่ = a−x) ✔
- แต่ **[HI] ไม่เท่ากับอีกสองตัว** — ดูจาก K:
K = [HI]²/([H₂][I₂]) = 47
ถ้าทั้งสามเท่ากันจริง แทนค่าจะได้ K = c²/(c·c) = **1** ไม่ใช่ 47
K = 47 (มากกว่า 1 มาก) แปลว่า **HI มีมากกว่าสารตั้งต้นชัดเจน**

**4) อัตราการรวมตัวของ H₂ กับ I₂ = อัตราการสลายตัวของ HI → ถูก** — นี่คือ **นิยาม** ของภาวะสมดุลไดนามิก

**5) โมล HI ที่เกิด = ผลรวมโมล H₂ กับ I₂ ที่ลดลง → ถูก**
H₂ ลด x + I₂ ลด x = **2x** และ HI ที่เกิด = **2x** ✔ ตรงกันพอดีตามสัมประสิทธิ์

**ตอบ 3**

### Q-0623 · สามัญ 2558 ข้อ 28 · hard
**Answer:** 2) K₁ = K₂² K₃
**Confidence:** ok
**Checked:** no
**Solution:**
**กฎการรวมค่า K (ต้องจำ 3 ข้อนี้ แล้วข้อนี้จบใน 3 บรรทัด):**

| ทำอะไรกับสมการ | ค่า K กลายเป็น |
|---|---|
| **กลับด้าน** สมการ | **1/K** |
| **คูณ n** ทั้งสมการ | **Kⁿ** |
| **บวก** สองสมการเข้าด้วยกัน | **คูณ K เข้าด้วยกัน** |

> 🔴 **จุดตายของข้อนี้: ค่า K รวมกันด้วยการ *คูณ/ยกกำลัง* เท่านั้น ห้ามบวกลบ**
> ตัวเลือก 3, 4, 5 ทั้งหมดมีเครื่องหมาย + หรือ − อยู่ในสูตร → **ตัดทิ้งได้ทันทีโดยไม่ต้องคำนวณ**

**สมการที่ให้มา:**
- (1) 2A₂ + B₂ ⇌ 2A₂B · K₁
- (2) A₂ + 2B₂ ⇌ 2AB₂ · K₂
- (3) 4AB₂ ⇌ 2A₂B + 3B₂ · K₃ ← **เป้าหมาย**

**ประกอบ (3) จาก (1) และ (2):**

**ขั้นที่ 1 — เอา (2) กลับด้านแล้วคูณ 2** (เพราะเป้าหมายมี 4AB₂ อยู่ฝั่งซ้าย ส่วน (2) มี 2AB₂ อยู่ฝั่งขวา)
กลับด้าน (2): 2AB₂ ⇌ A₂ + 2B₂ · K = 1/K₂
คูณ 2: **4AB₂ ⇌ 2A₂ + 4B₂** · K = (1/K₂)² = **1/K₂²**

**ขั้นที่ 2 — บวกกับ (1) ตามเดิม**
**2A₂ + B₂ ⇌ 2A₂B** · K = K₁

**ขั้นที่ 3 — รวมกัน**
```
4AB₂  + 2A₂ + B₂   ⇌   2A₂ + 4B₂ + 2A₂B
```
ตัด 2A₂ ทั้งสองข้าง และตัด B₂ ออกจาก 4B₂ เหลือ 3B₂:
```
4AB₂ ⇌ 2A₂B + 3B₂   ✔ ตรงกับสมการ (3) เป๊ะ
```

**ขั้นที่ 4 — คูณค่า K**
K₃ = (1/K₂²) × K₁ = **K₁/K₂²**

จัดรูปใหม่: **K₁ = K₂² · K₃** → **ตอบ 2**

*(ตัวเลือก 1 ผิดเพราะมีเลข 2 คูณอยู่หน้า K₂ — ค่า K ไม่มีทางถูกคูณด้วยเลขสัมประสิทธิ์ตรงๆ มีแต่ยกกำลัง)*

*(ทางลัด: หา n/V ตรงๆ ก็ได้ — [SO₂Cl₂]₀ = P/RT = 1.64 ÷ 32.84 = 0.05 mol/dm³ ไม่ต้องแวะหา n เลย)*

**ขั้นที่ 2 — กุญแจของข้อนี้: 1 โมเลกุลแตกตัวได้ 2 โมเลกุล → โมลรวมเพิ่ม**

| | SO₂Cl₂ | SO₂ | Cl₂ | **รวม** |
|---|---|---|---|---|
| เริ่ม | 0.05 | 0 | 0 | 0.05 |
| เปลี่ยน | −x | +x | +x | **+x** |
| สมดุล | 0.05−x | x | x | **0.05 + x** |

**ขั้นที่ 3 — ใช้ความเข้มข้นรวมที่โจทย์ให้**

%แตกตัว = (x ÷ ความเข้มข้นเริ่มต้น) × 100 = (0.04 ÷ 0.05) × 100 = **80%**

**ตอบ 4**

| สาร | mol | [ ] = mol ÷ 0.5 |

### Q-0955 · PAT2 2553 (มี.ค.) ข้อ 33 · medium

**Solution:**

เมื่อ **Δn = 0** → (RT)⁰ = 1 → **Kp = Kc**

| ข้อ | สมการที่ดุลแล้ว | โมลแก๊สซ้าย | โมลแก๊สขวา | Δn |
|---|---|---|---|---|

### Q-1241 · PAT2 2553 (ก.ค.) ข้อ 19 · medium
**Answer:** 1) ab
**Confidence:** ok
**Checked:** no
**Solution:**
**กลไก 2 ขั้นของการสลายโอโซนโดยอะตอมคลอรีน:**
- ขั้นที่ 1: O₃ + Cl ⇌ O₂ + OCl · K = **a**
- ขั้นที่ 2: O₃ + OCl ⇌ 2O₂ + Cl · K = **b**
- รวม: 2O₃ ⇌ 3O₂ · K = **c**

**กฎเดียวที่ใช้:** สมการ **บวก** กัน → ค่า K **คูณ** กัน (มาจากการที่ K เป็นผลคูณของอัตราส่วนความเข้มข้น)

**พิสูจน์ว่าสองขั้นบวกกันได้สมการรวมจริง:**
```
  O₃ + Cl        ⇌  O₂ + OCl
  O₃ + OCl       ⇌  2O₂ + Cl
──────────────────────────────────
  2O₃ + Cl + OCl ⇌ 3O₂ + Cl + OCl
```
**Cl** และ **OCl** ปรากฏทั้งสองฝั่ง → **ตัดทิ้งทั้งคู่**
→ **2O₃ ⇌ 3O₂** ✔ ตรงกับปฏิกิริยารวม

**ดังนั้น c = a × b = ab** → **ตอบ 1**

**ทำไมถึงเป็นการคูณ (ไม่ต้องท่อง):**
a = ([O₂][OCl]) ÷ ([O₃][Cl]) · b = ([O₂]²[Cl]) ÷ ([O₃][OCl])
คูณกัน: ab = ([O₂][OCl][O₂]²[Cl]) ÷ ([O₃][Cl][O₃][OCl])
**[OCl] และ [Cl] ตัดกันหมด** → ab = [O₂]³ ÷ [O₃]² = **c** ✔

**เกร็ดที่ทำให้จำได้:** Cl กับ OCl ตัดออกหมดเพราะเป็น **ตัวเร่งปฏิกิริยาและสารมัธยันตร์** — Cl ถูกใช้ในขั้นที่ 1 แล้ว **ได้คืนในขั้นที่ 2** จึงทำลาย O₃ ได้ซ้ำๆ นับหมื่นครั้ง นี่คือเหตุผลที่ CFC ปริมาณนิดเดียวทำลายชั้นโอโซนได้มหาศาล

### Q-1243 · PAT2 2553 (ก.ค.) ข้อ 21 · medium
**Answer:** 2) ปฏิกิริยาที่จะมีสมดุลได้ ต้องเป็นปฏิกิริยาในระบบปิดเท่านั้น
**Confidence:** ok
**Checked:** no
**Solution:**
**ไล่ทีละข้อ:**

**1) "ค่าคงที่สมดุลจะมีค่ามากขึ้นเมื่ออุณหภูมิสูงขึ้นเสมอ" → ผิด**
คำว่า **"เสมอ"** คือจุดตาย ทิศทางที่ K เปลี่ยนขึ้นกับว่าปฏิกิริยา **ดูดหรือคาย** ความร้อน:
- **ดูดความร้อน** (ความร้อนเป็นสารตั้งต้น): เพิ่ม T → เลื่อนขวา → **K เพิ่ม**
- **คายความร้อน** (ความร้อนเป็นผลิตภัณฑ์): เพิ่ม T → เลื่อนซ้าย → **K ลด**
เช่น การสังเคราะห์ NH₃ ซึ่งคายความร้อน ค่า K **ลดลง** เมื่ออุณหภูมิสูงขึ้น

**2) "ปฏิกิริยาที่จะมีสมดุลได้ ต้องเป็นปฏิกิริยาในระบบปิดเท่านั้น" → ถูก ✔**
สมดุลไดนามิกต้องการให้ **ปฏิกิริยาย้อนกลับเกิดได้** ซึ่งแปลว่าผลิตภัณฑ์ต้องอยู่ในระบบ
ระบบเปิด → ผลิตภัณฑ์ (โดยเฉพาะแก๊ส) หนีออกไปเรื่อยๆ → ปฏิกิริยาย้อนกลับไม่มีวันไล่ทัน → **ความเข้มข้นไม่มีวันคงที่ = ไม่มีวันถึงสมดุล**
*(ตัวอย่างคลาสสิก: เผา CaCO₃ ในบีกเกอร์เปิด CO₂ ลอยหนีหมด ปฏิกิริยาเดินไปข้างหน้าจนสารตั้งต้นหมด — ไม่เคยเข้าสมดุลเลย แต่ถ้าเผาในภาชนะปิด จะเกิดสมดุล CaCO₃ ⇌ CaO + CO₂)*

**3) "ถ้า K > 1 แสดงว่ามีผลิตภัณฑ์มากกว่าสารตั้งต้นที่เหลืออยู่เสมอ" → ผิด**
คำว่า **"เสมอ"** ตายอีกแล้ว — K บอกแค่ว่า **นิพจน์** ของผลิตภัณฑ์หารสารตั้งต้นมีค่ามากกว่า 1 ไม่ได้บอกว่าความเข้มข้นดิบตัวไหนมากกว่า เพราะมี **เลขยกกำลังจากสัมประสิทธิ์** อยู่ในนิพจน์

**ตัวอย่างค้าน:** A ⇌ 2B โดย K = 2
K = [B]²/[A] = 2 · ถ้า [A] = 8 → [B]² = 16 → **[B] = 4**
→ K > 1 แต่ **[B] = 4 น้อยกว่า [A] = 8** ✘ ข้อความจึงผิด

**4) "มีคำตอบถูกมากกว่า 1 ข้อ" → ผิด** เพราะมีข้อ 2 ถูกอยู่ข้อเดียว

**ตอบ 2**

*(บทเรียนที่ใช้กับข้อสอบทุกวิชา: เจอคำว่า **"เสมอ" / "เท่านั้น" / "ทุกครั้ง"** ให้หยุดแล้วลองหาตัวอย่างค้านทันที — ข้อ 1 กับ 3 ตายด้วยคำว่า "เสมอ" ส่วนข้อ 2 ใช้คำว่า "เท่านั้น" แล้วรอด เพราะมันเป็นเงื่อนไขจำเป็นจริงๆ)*

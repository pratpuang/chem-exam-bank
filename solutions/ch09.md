### Q-0617 · สามัญ 2558 ข้อ 22 · medium
**Answer:** 1) 3.60 × 10⁻⁵
**Confidence:** ok
**Checked:** no
**Solution:**
**สมการ:** Br₂(aq) + HCOOH(aq) → 2Br⁻(aq) + 2H⁺(aq) + CO₂(g)

**ขั้นที่ 1 — อ่านสิ่งที่โจทย์ให้จริงๆ**
สิ่งที่ **วัดได้** คือ Br⁻ ที่เกิดขึ้น = 7.20 × 10⁻³ mol ในเวลา 100 s
สิ่งที่ **ถาม** คือ อัตราการลดลงของ Br₂ — คนละสารกัน ต้องแปลงด้วยเลขสัมประสิทธิ์ก่อน

**ขั้นที่ 2 — ใช้อัตราส่วนโมลจากสมการ**
Br₂ 1 mol → Br⁻ **2** mol
ดังนั้น Br₂ ที่หายไป = ½ ของ Br⁻ ที่เกิด

n(Br₂ ที่ลดลง) = (1/2)(7.20 × 10⁻³) = **3.60 × 10⁻³ mol**

**ขั้นที่ 3 — หารด้วยเวลา**
อัตราการลดลงของ Br₂ = 3.60 × 10⁻³ mol ÷ 100 s = **3.60 × 10⁻⁵ mol/s**

**ตอบ 1**

*(เช็คความสมเหตุสมผล: Br₂ มีตั้งต้น 0.0120 mol ใช้ไป 0.0036 mol = 30% — ยังเหลือ ผ่าน · HCOOH 0.0500 mol มากเกินพอ เป็นแค่ตัวหลอก)*
*(กับดักของข้อนี้คือ **7.20 × 10⁻⁵** ในตัวเลือก 2 — คือคนที่หารเวลาแล้วลืมหาร 2)*

### Q-0618 · สามัญ 2558 ข้อ 23 · medium
**Answer:** 1) ปริมาตรแก๊ส / ปริมาตรแก๊ส / ปริมาณตะกอน
**Confidence:** ok
**Checked:** no
**Solution:**
**หลักคิดเดียวของข้อนี้:** จะติดตามอัตราได้ ต้องเลือกสมบัติที่ **เปลี่ยนแปลงชัดและวัดได้ตลอดเวลา** — มองหา "สารที่โผล่ขึ้นมาใหม่หรือหายไป แล้ววัดง่าย"

**ก. Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g)**
มี **แก๊ส H₂** ผุดออกมา → เก็บแก๊สแล้ววัด **ปริมาตรแก๊ส** ต่อเวลา ตรงไปตรงมา ✔
*(pH ก็เปลี่ยนจริง เพราะ HCl ถูกใช้ไป — แต่ pH เป็นสเกล log ช่วงต้นเปลี่ยนน้อยมาก วัดอัตราได้แย่กว่าแก๊สเยอะ)*

**ข. 2KClO₃(s) → 2KCl(s) + 3O₂(g)**
ของแข็ง → ของแข็ง + **แก๊ส O₂** สิ่งเดียวที่วัดง่ายคือ **ปริมาตรแก๊ส** ✔
*(ตะกอนวัดไม่ได้ เพราะทั้งสองฝั่งเป็นของแข็งอยู่แล้ว มวลรวมแทบไม่บอกอะไร)*

**ค. Ca(OH)₂(aq) + CO₂(g) → CaCO₃(s) + H₂O(l)**
เกิด **CaCO₃ ตะกอนขาว** ขึ้นมาใหม่ → วัด **ปริมาณตะกอน** (หรือความขุ่น) ✔

รวมได้ **ปริมาตรแก๊ส / ปริมาตรแก๊ส / ปริมาณตะกอน** → **ตอบ 1**

*(ตัดข้ออื่นเร็วๆ: ทุกข้อที่ให้ ข. เป็น "ปริมาณตะกอน" หรือ "อุณหภูมิ" ตกทันที เพราะ ข. ไม่มีตะกอนใหม่ และการวัดอุณหภูมิใช้ติดตามอัตราได้แย่มาก)*

### Q-0619 · สามัญ 2558 ข้อ 24 · hard
**Answer:** 5) อัตราการเกิดปฏิกิริยาที่สภาวะ (ก) ต่ำกว่าที่สภาวะ (ข) เพราะที่สภาวะ (ก) โมเลกุลที่มีพลังงานจลน์สูงมีจำนวนน้อยกว่า
**Confidence:** ok
**Checked:** no
**Solution:**
**สิ่งที่ต้องรู้ก่อน — รูปร่างกราฟแมกซ์เวลล์–โบลต์ซมันน์เมื่ออุณหภูมิสูงขึ้น** (ที่นี่ (ก) = T °C, (ข) = 5T °C):
- **พื้นที่ใต้กราฟเท่าเดิม** — จำนวนโมเลกุลทั้งหมดไม่เปลี่ยน แค่กระจายพลังงานใหม่
- ยอดกราฟ **เตี้ยลงและเลื่อนไปทางขวา** กราฟ **แผ่กว้างขึ้น**
- ผลคือ **หางขวา (โมเลกุลพลังงานสูง) หนาขึ้นมาก** → จำนวนโมเลกุลที่มี E ≥ Eₐ เพิ่มขึ้นแบบก้าวกระโดด

**ไล่ทีละข้อ:**
- **1)** คาย/ดูดความร้อนถูกกำหนดโดย **ΔH ของปฏิกิริยา** ไม่เกี่ยวกับอุณหภูมิที่ทำการทดลอง เปลี่ยน T ไม่ได้เปลี่ยนปฏิกิริยาคายเป็นดูด ✘
- **2)** **Eₐ เป็นสมบัติของปฏิกิริยา ไม่ใช่ของอุณหภูมิ** — เป็นสารตัวเดียวกัน เส้นทางเดียวกัน Eₐ เท่ากันเป๊ะทั้งสองสภาวะ ✘ *(นี่คือกับดักใหญ่สุดของบทนี้: เพิ่มอุณหภูมิ ≠ ลด Eₐ · สิ่งที่ลด Eₐ มีอย่างเดียวคือตัวเร่งปฏิกิริยา)*
- **3)** ที่ T สูงกว่า กราฟ **เตี้ยลง** → โมเลกุลที่มีพลังงานเท่ากับค่าเฉลี่ยจะ **น้อยลง** ไม่ใช่มากขึ้น ข้อนี้กลับด้าน ✘
- **4)** จำนวนโมเลกุลทั้งหมด = พื้นที่ใต้กราฟ = **เท่ากันทั้งสองสภาวะ** ✘
- **5)** ที่ (ก) อุณหภูมิต่ำกว่า → หางขวาบางกว่า → โมเลกุลที่มี E ≥ Eₐ น้อยกว่า → **ชนแบบมีประสิทธิภาพน้อยกว่า → อัตราต่ำกว่า** ✔

**ตอบ 5** — และเหตุผลที่ข้อ 5 ให้มาก็คือกลไกที่ถูกต้องจริงๆ ไม่ใช่แค่ผลลัพธ์ถูก

### Q-0667 · สามัญ 2555 ข้อ 22 · hard
**Answer:** 2) ข และ ค เท่านั้น
**Confidence:** ok
**Checked:** no
**Solution:**
**สมการ:** A + 3B → 2C + D
**อ่านกราฟก่อน** (`images/Q-0667.png`): B เริ่มที่ 2.0 · A เริ่มที่ 1.0 · C กับ D เริ่มที่ 0
ค่าสุดท้าย (นิ่งแล้ว): A ≈ 0.40 · B ≈ 0.20–0.25 · C ≈ 1.15 · D ≈ 0.55
เช็คว่าอ่านถูก: ΔA ≈ 0.6, ΔB ≈ 1.8 = 3ΔA ✔, ΔC ≈ 1.2 = 2ΔA ✔, ΔD ≈ 0.6 = ΔA ✔ — ตรงสมการ

**หัวใจ: อัตราการเกิดปฏิกิริยา (r) ต้องหารด้วยเลขสัมประสิทธิ์เสมอ**
r = −Δ[A]/Δt = −(1/3)Δ[B]/Δt = +(1/2)Δ[C]/Δt = +Δ[D]/Δt

**ก. ที่ 4 s อัตราการลดลงของ B = อัตราการเกิดของ C**
อัตราการลดลงของ B = **3r** · อัตราการเกิดของ C = **2r**
3r ≠ 2r ณ เวลาใดๆ (เว้นแต่ r = 0 ซึ่งที่ 4 s ยังไม่นิ่ง) → **ผิด**
*(ตรงนี้ตัดตัวเลือก 1, 4, 5 ทิ้งทันที เหลือแค่ 2 กับ 3 — ต่างกันแค่ข้อ ง)*

**ข. อัตราเฉลี่ยช่วง 2 วินาทีแรก < 0.4 mol dm⁻³ s⁻¹**
ใช้ A: ที่ t = 0 → 1.0, ที่ t = 2 → ประมาณ 0.75
r = (1.0 − 0.75)/2 ≈ **0.13 mol dm⁻³ s⁻¹**
เช็คซ้ำด้วย B: ที่ t = 2 → ประมาณ 1.2 · r = (2.0 − 1.2)/(3 × 2) ≈ **0.13** ✔ ตรงกัน
0.13 < 0.4 → **ถูก**

**ค. ที่ 4 s อัตราน้อยกว่าที่ 2 s**
ความชันของทุกเส้นแบนลงเรื่อยๆ ตามเวลา (สารตั้งต้นเจือจางลง โอกาสชนน้อยลง) → **ถูก**

**ง. ปฏิกิริยาเกิดสมบูรณ์เมื่อผ่านไป 8 วินาที** → **ผิด 2 ชั้น**
1. กราฟ **แบนตั้งแต่ประมาณ 6 s แล้ว** ไม่ใช่ 8 s
2. คำว่า "สมบูรณ์" แปลว่าสารตั้งต้นหมด แต่กราฟค้างไว้ที่ A ≈ 0.40 และ B ≈ 0.2 — **สารตั้งต้นเหลือทั้งคู่** ระบบแค่เข้าสู่สมดุล/หยุดเปลี่ยน ไม่ได้เกิดจนหมด

เหลือ **ข และ ค** → **ตอบ 2**

ดุล N: ซ้าย 2N ต่อ 1 โมเลกุล → ใส่ 2 หน้า NO₂

**2N₂O₅(g) → 4NO₂(g) + O₂(g)**
เช็ค: N ซ้าย 4 = ขวา 4 ✔ · O ซ้าย 10 = ขวา 8 + 2 = 10 ✔

**ขั้นที่ 2 — ใช้อัตราส่วนโมล**

### Q-0975 · PAT2 2553 (มี.ค.) ข้อ 53 · hard
**Answer:** 1) 0.125
**Confidence:** ok
**Checked:** no
**Solution:**
**สมการ:** 2A(aq) → B(aq) · กำหนด **[A] = 4 − √t**

**หัวใจ: โจทย์ให้ความเข้มข้นเป็น *ฟังก์ชันของเวลา* ไม่ใช่ตาราง → ต้องหาอัตรา *ขณะนั้น* ด้วยความชัน (อนุพันธ์) ไม่ใช่เฉลี่ย**

[A] = 4 − t^(1/2)
d[A]/dt = −(1/2)·t^(−1/2) = **−1/(2√t)**

**ขั้นที่ 2 — แทน t = 4 s**
d[A]/dt = −1/(2√4) = −1/(2 × 2) = **−0.25**
→ A ลดลงด้วยอัตรา 0.25 หน่วยความเข้มข้นต่อวินาที (เครื่องหมายลบ = ลดลง)

r = −(1/2)(d[A]/dt) = −(1/2)(−0.25) = **0.125**

**ตอบ 1**

**ถ้ายังไม่เคยเรียนอนุพันธ์ — ทำแบบประมาณช่วงสั้นก็ได้ผลเดียวกัน:**
ที่ t = 3.9 s: [A] = 4 − √3.9 = 4 − 1.9748 = 2.0252
ที่ t = 4.1 s: [A] = 4 − √4.1 = 4 − 2.0248 = 1.9752
Δ[A]/Δt = (1.9752 − 2.0252)/0.2 = −0.250 → r = 0.125 ✔ ตรงกัน

*(กับดัก: **0.250** (ข้อ 2) คือคนที่ลืมหารด้วยสัมประสิทธิ์ 2 · **0.500** (ข้อ 4) คือคนที่หาความชันผิดเป็น 1/√t)*

| ลูกศร | วัดจาก → ถึง | ความหมาย |
|---|---|---|

| **B** | หลุม ค → ระดับ จ | ค สูงกว่า จ เท่าไร |

กำแพงแรกที่ จ ต้องเจอคือ **ยอด ง** และความสูงจาก จ ขึ้นถึง ง คือ **C** พอดี
ถ้าให้พลังงานน้อยกว่า C → **โมเลกุลที่ จ ขยับกลับไม่ได้เลยแม้แต่ก้าวเดียว**

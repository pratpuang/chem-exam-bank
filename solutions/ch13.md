### Q-0637 · สามัญ 2558 ข้อ 42 · medium
**Answer:** 4) ค และ ง เท่านั้น
**Confidence:** ok
**Checked:** no
**Solution:**
ไล่ตรวจการเรียกชื่อทีละข้อ:

**ก. CH₃–CH(CH₃)–CH(CH₃)–C(CH₃)₂–CH₃ → อ้างว่าชื่อ "3,4,5,5-tetramethylhexane" → ผิด**
โครงสร้างนี้โซ่ยาวที่สุดคือ **เพนเทน (5 คาร์บอน)** ไม่ใช่เฮกเซน — นับคาร์บอนทั้งหมด = 5 (โซ่หลัก) + 4 (หมู่เมทิล) = 9 อะตอม (C₉H₂₀)
ชื่อที่ถูกคือ **2,3,4,4-tetramethylpentane** (ไล่เลขจากปลายที่ให้ตำแหน่งต่ำสุด)
การเรียกว่า "hexane" ทั้งที่โซ่หลักมีแค่ 5 คาร์บอน จึงผิดตั้งแต่ชื่อโซ่หลัก

**ข. CH₃–CH(CH₃)–C(CH₃)=CH–CH₃ → อ้างว่า "2,3-dimethyl-3-pentene" → ผิด**
โซ่หลัก = เพนทีน 5 คาร์บอน มีพันธะคู่
🔴 **กฎเหล็ก: พันธะคู่ต้องได้เลขตำแหน่งต่ำที่สุด** ไล่จากขวา พันธะคู่อยู่ตำแหน่ง **2** (pent-2-ene) ไล่จากซ้ายได้ 3
ต้องเลือกเลขต่ำ = pent-2-ene แล้วหมู่เมทิลจะไปอยู่ตำแหน่ง 3,4
ชื่อที่ถูก = **3,4-dimethylpent-2-ene** ไม่ใช่ "3-pentene"

**ค. CH₃–C(=O)–O–(CH₂)₇CH₃ → "octyl acetate" → ถูก ✔**
เป็นเอสเทอร์: ส่วนกรด = CH₃COO– (จากกรดแอซีติก → "acetate/ethanoate")
ส่วนแอลกอฮอล์ = –(CH₂)₇CH₃ = 8 คาร์บอน = **octyl**
รวม = octyl acetate ✔

**ง. CH₃–CH[N(CH₃)₂]–CH₂–CH₂–CH₃ → "N,N-dimethyl-2-pentanamine" → ถูก ✔**
โซ่หลัก = เพนเทน (5C) หมู่ –NH ที่ถูกแทนที่อยู่ที่ C2 → pentan-2-amine
มีเมทิล 2 หมู่บนไนโตรเจน → **N,N-dimethylpentan-2-amine** ✔

สรุป: ถูกเฉพาะ **ค และ ง** → **ตอบ 4**

### Q-0639 · สามัญ 2558 ข้อ 44 · hard
**Answer:** 5) สาร Y เป็นสารประกอบไฮโดรคาร์บอนอิ่มตัว
**Confidence:** ok
**Checked:** no
**Solution:**
**ถอดรหัสสาร X Y Z จากปฏิกิริยาก่อน:**

**X + Br₂ → C₄H₈Br₂** (เติม Br 2 อะตอม, ไม่มี HBr หลุด) = **ปฏิกิริยาการเติม** → X มีพันธะคู่
→ **X = บิวทีน C₄H₈** (แอลคีน)

**Y + Br₂ → C₅H₁₁Br + HBr** (มี HBr หลุด) = **ปฏิกิริยาการแทนที่** → Y เป็นสารอิ่มตัว
→ **Y = เพนเทน C₅H₁₂** (แอลเคน)

**2Z + 15O₂ → 10CO₂ + 10H₂O** หารด้วย 2: Z + 7.5O₂ → 5CO₂ + 5H₂O
→ Z มี C = 5, H = 10 → **Z = C₅H₁₀** (เช็คออกซิเจน: 10+5 = 15 O = 7.5 O₂ ✔)

**ไล่ตัวเลือก:**
1) Z ไม่ทำปฏิกิริยากับ Br₂ → **ผิด** — C₅H₁₀ อาจเป็นแอลคีนซึ่งทำปฏิกิริยากับ Br₂ ได้ สรุปแบบฟันธงไม่ได้
2) X ไม่ทำปฏิกิริยากับ KMnO₄ → **ผิด** — X เป็นแอลคีน ทำปฏิกิริยากับ KMnO₄ (ฟอกสีม่วง) ได้
3) Y และ Z มีสูตรทั่วไปเหมือนกัน → **ผิด** — Y = CₙH₂ₙ₊₂ (แอลเคน), Z = CₙH₂ₙ ต่างกัน
4) X และ Y มีจำนวนไอโซเมอร์ไม่เท่ากัน → ก้ำกึ่ง/ไม่ใช่ประเด็นหลัก
5) **Y เป็นไฮโดรคาร์บอนอิ่มตัว → ถูก ✔** — Y = เพนเทน (C₅H₁₂) เป็นแอลเคน อิ่มตัวเต็มที่แน่นอน

**ตอบ 5** (เป็นข้อเดียวที่ฟันธงถูกได้ 100% จากข้อมูลที่ถอดได้)

### Q-0640 · สามัญ 2558 ข้อ 45 · medium
**Answer:** 3) ก ค และ ง
**Confidence:** ok
**Checked:** no
**Solution:**
**หลักการเดียวที่ใช้ทั้งข้อ:** โลหะ Na ทำปฏิกิริยากับหมู่ **–OH (แอลกอฮอล์)** และ **–COOH (กรด)** เกิดฟองแก๊ส H₂ · แต่ **ไม่ทำปฏิกิริยากับอีเทอร์และเอสเทอร์**
"บอกความแตกต่างไม่ได้" = ทั้งคู่ให้ผลกับ Na **เหมือนกัน** (เกิดฟองทั้งคู่ หรือไม่เกิดทั้งคู่)

| คู่ | สารซ้าย | สารขวา | ผลกับ Na |
|---|---|---|---|
| ก | CH₃COOH (กรด, เกิด H₂) | CH₃CH₂OH (แอลกอฮอล์, เกิด H₂) | เกิดทั้งคู่ → **แยกไม่ได้** ✔ |
| ข | อีเทอร์ (ไม่เกิด) | บิวทานอล (เกิด H₂) | ต่างกัน → แยกได้ |
| ค | เอสเทอร์ (ไม่เกิด) | เอสเทอร์ (ไม่เกิด) | ไม่เกิดทั้งคู่ → **แยกไม่ได้** ✔ |
| ง | บิวทานอล (เกิด) | โพรพานอล (เกิด) | เกิดทั้งคู่ → **แยกไม่ได้** ✔ |
| จ | เอสเทอร์ (ไม่เกิด) | โพรพานอล (เกิด) | ต่างกัน → แยกได้ |

แยกความแตกต่างด้วย Na ไม่ได้ = **ก ค และ ง** → **ตอบ 3**

### Q-0644 · สามัญ 2558 ข้อ 49 · medium
**Answer:** 5) เมื่อไฮโดรไลส์จะได้กรดอะมิโน 3 ชนิด
**Confidence:** ok
**Checked:** no
**Solution:**
**อ่านภาพ:** ไตรเพปไทด์ H₂N–CH(R₁)–CO–NH–CH(R₂)–CO–[โพรลีน]–COOH
โดย R₁ และ R₂ เป็นหมู่ข้างเคียงที่มี **–COOH (โซ่ CH₂CH₂COOH เหมือนกันทั้งคู่ = กรดกลูตามิก)** และตัวที่สามเป็น **โพรลีน** (วงแหวน)

โจทย์ถามข้อที่ **ผิด**:
1) จัดเป็นไตรเพปไทด์ → **ถูก** (กรดอะมิโน 3 หน่วยต่อกัน)
2) มีพันธะเพปไทด์ 2 พันธะ → **ถูก** (n หน่วย = n−1 พันธะ; 3 หน่วย = 2 พันธะ)
3) ละลายน้ำได้สารละลายกรด → **ถูก** — มี –COOH อิสระ 3 หมู่ (side chain 2 + ปลายโพรลีน 1) เทียบกับ –NH₂ ปลายเพียง 1 → สุทธิเป็นกรด
4) ให้สีม่วงกับไบยูเร็ต → **ถูก** — การทดสอบไบยูเร็ตต้องมีพันธะเพปไทด์ ≥ 2 พันธะ ไตรเพปไทด์มีพอดี 2 → ให้ผลบวก (สีม่วง)
5) **ไฮโดรไลส์ได้กรดอะมิโน 3 ชนิด → ผิด ✔ ตอบข้อนี้**

- พันธะ **Ar(ซ้าย)–O** = C อะโรมาติก–O → **ถูกตัด**

ออกก่อน = **Q** (จุดเดือดต่ำสุด) · ออกสุดท้าย = **R** (โมเลกุลใหญ่สุด จุดเดือดสูงสุด)

### Q-1310 · A-level 2568 ข้อ 33 · hard

**Solution:**
**โจทย์:** X = CₘHₙNqOr · X 1 mol + กรดแอซีติก (H₂SO₄) เกิดสมบูรณ์ ได้น้ำ 2 mol → Y · Y ฟอกจางสี Br₂ ในที่มืด → Z (ดูภาพ) · หา 1000m + 100n + 10q + r
**วิธี: ย้อนจาก Z → Y → X**

**ขั้นที่ 1 — อ่านสูตรของ Z จากภาพ**
Z = วงไพเพอราซิโนน 6 เหลี่ยม (N 2 ตัว) โดย:
- N ตัวหนึ่งมีหมู่แอซีทิล (N–CO–CH₃)
- N อีกตัวมีหมู่ –CH₂–O–CO–CH₃ (แอซีเตตเอสเทอร์บน CH₂)
- คาร์บอน 2 ตัวในวงมี Br ตัวละ 1 (–CHBr–CHBr–)
- มีหมู่ C=O ในวง (แลกแทม) 1 ตำแหน่ง
นับได้ **Z = C₉H₁₂Br₂N₂O₄**

**ขั้นที่ 2 — ย้อน Z → Y (Y + Br₂ → Z)**
Z เกิดจาก Y ฟอกจางสี Br₂ ในที่มืด = **การเติม Br₂ ที่พันธะคู่ C=C** (คาร์บอน 2 ตัวที่มี Br คือ C=C เดิม)
→ Y = Z − Br₂ (คาร์บอนคู่นั้นกลับเป็นพันธะคู่) = **C₉H₁₂N₂O₄**

**ขั้นที่ 3 — ย้อน Y → X (X + กรดแอซีติก 2 mol → Y + น้ำ 2 mol)**
